# Безопасность

Этот репозиторий предназначен для локального развёртывания и разработки. Файлы `.env` намеренно не входят в Git: bootstrap создаёт их из `.env.example` при первом запуске.

Не публикуйте в Issues, Pull Requests, документации или Git историю:

- SSH-пароли, приватные ключи и токены;
- реальные OAuth credentials;
- production database credentials;
- JWT, API keys и содержимое `vk_auth.json`.

Если секрет уже попал в публичную историю, считайте его скомпрометированным: отзовите или смените его, затем удалите из истории отдельной процедурой очистки Git.

Локальный аккаунт из `.env.example` предназначен только для dev-режима. Перед любым доступом из недоверенной сети измените его пароль и выключите `LOCAL_AUTH_ENABLED`.
